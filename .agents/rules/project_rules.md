# Project Rules and Guidelines

## 1. Naming and Syntax Rules
* **No Hyphens:** Hyphens (-) are strictly forbidden in the repository name, project name, file paths, directory names, or codebase conventions.

## 2. Emoji Usage Policy
* **No Emojis by Default:** Do not use emojis anywhere in the project, documentation, UI, or commit messages.
* **Sole Exception:** Emojis are only permitted if explicitly added by the original author or if the original author specifically instructs to add them.

## 3. Authorship and Attribution
* **Sole Author:** IboTV is the sole and only author of this project.
* **No Outside Contributions:** No external contributions, co-authorship, or outside third-party credits are allowed.

## 4. Data & Connectivity Standards
* **Zero Mock Data:** Mock data, placeholder dynamic lists, dummy fixtures, and hardcoded static objects are strictly forbidden.
* **Full Stack Integration:** All features, data flows, UI components, and backend endpoints must be fully connected and operational end-to-end.
